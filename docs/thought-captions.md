# Заголовки мыслей

## Данные и отображение

`src/thought-transcript.js` нормализует native reasoning в блоки с полями
`sessionId`, `turnId`, `id`, `text`, `completed`, `revision`, `epoch`.
`SessionClient` сохраняет `session.reasoning.ended`. При восстановлении истории
завершение сообщения или следующий элемент упорядоченного потока также завершает
предыдущий блок. Известное завершение сохраняется при переподключении.

`src/thought-caption.js` содержит общую чистую политику извлечения подписи:

- завершённая однострочная мысль до 120 символов;
- законченная строка Markdown-заголовка или выделенного жирным заголовка;
- асинхронная сводка, если у блока нет прямой подписи.

Store хранит блоки и отдельно сводки. Значение `activityThought` — проекция этих
данных. Тот же блок передаётся в `nativeThought` для рендеринга текста и признака
стриминга. ACP-адаптер создаёт отдельные идентификаторы блоков, даже если несколько
мыслей принадлежат одному сообщению.

## Подключение модели

`src/thought-summarizer.js` — координатор в extension host. `SessionClient`
принимает опциональный `summarizeThought`:

```js
async function summarizeThought({
  sessionId, turnId, blockId, revision, completed, text, signal,
}) {
  // Вызов выбранного провайдера с коротким лимитом ответа и AbortSignal.
  return 'Проверяю зависимости экспорта';
}
```

По умолчанию провайдер отключён. Выбор модели и её настройки подключаются к этому
интерфейсу отдельной интеграцией. Смена провайдера доступна через
`client.thoughtSummarizer.setProvider(provider)`.

Координатор передаёт последние 6000 символов текущего блока, запускает максимум
один запрос на сессию и выдерживает минимум 1 секунду между запусками. Новые
обновления объединяются; непрерывный поток не сдвигает срок следующего запуска.
Deadline 10 секунд отменяет запрос через `AbortSignal`. Провайдер должен
поддерживать отмену; следующий запрос начинается после завершения предыдущего.
Ошибка сохраняет обычный механизм подписей; повтор возможен на новой версии текста.

Результат приходит в webview как `thoughtCaption` и сохраняется для replay
снапшота. Он содержит идентификаторы исходного блока, `revision`, `epoch` и строку
подписи. Дописывание того же блока допускает сводку более ранней версии. Замена
текста меняет `epoch`; новый блок, завершение хода, смена провайдера или закрытие
клиента отменяют устаревшие запросы. Store дополнительно проверяет идентичность
блока и порядок версий перед применением результата.

Проверки: `test/thought-captions.js` запускается из `test/session-client.js`;
браузерные сценарии находятся в `test/ui/native-thought-captions.spec.js`.
